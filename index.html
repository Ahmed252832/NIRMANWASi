User roles

Four user roles in one system.

Each role sees the pages and actions it needs.

01 / ADMIN

Manage the system

Manage users, contractors, projects, payments, complaints and tenders.

02 / EMPLOYEE

Employee work

Employees can publish tenders, confirm bookings, verify payments and resolve complaints.

03 / CLIENT

Client activities

Clients can view properties, make bookings, check payments and send complaints.

04 / REPRESENTATIVE

Bids and updates

Representatives can view tenders, submit bids and post project updates.
